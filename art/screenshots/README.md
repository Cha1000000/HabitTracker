# Скриншоты HabitTracker

В этой папке лежат плейсхолдеры. Заменить их реальными скриншотами приложения перед публикацией.

## Какие файлы заменить
- `habits_list.png` — список привычек (основной экран)
- `add_edit_habit.png` — экран создания/редактирования привычки
- `group_habit_detail.png` — экран групповой привычки (детали, участники, прогресс)
- `friends_tabs.png` — социальный экран (друзья/поиск/заявки)

## Требования к скриншотам
- Разрешение: 1080×2400 (или 1080×2340) px, портретная ориентация
- Формат: PNG (предпочтительно без сжатия артефактов)
- Тема: светлая (или предоставьте оба варианта — светлая/тёмная)
- Чистота: без персональных данных, закрытые уведомления, стабильное состояние UI
- Консистентность: одинаковые поля статуса/навигации, один и тот же девайс/эмулятор

## Рекомендации
- Делайте скриншоты после прогрева UI, чтобы избежать «мигания»/скелетонов
- Старайтесь показывать ключевые фичи (анимации, валидация, прогресс)
- Для тёмной темы используйте отдельный набор файлов с суффиксом `_dark` и при необходимости обновите ссылки в корневом `README.md`

## Обновление README
В файле `README.md` в корне репозитория уже указана структура и имена файлов. 
После замены PNG-файлов скриншоты автоматически появятся при просмотре README на GitHub.
