## План реализаций ближайших фичей


### 🚀 1. UX и Вовлечение (Product Growth)

- **Интерактивные виджеты (Homescreen Widgets)**

    - Зачем: Самая важная фича для трекеров. Пользователи хотят отмечать привычки прямо с домашнего экрана, не заходя в приложение.
    - Реализация: Glance (Jetpack Compose for Widgets).

- **Библиотека шаблонов (Onboarding)**

    - Зачем: Проблема "чистого листа". Новым пользователям сложно придумать привычки.
    - Идея: Готовые наборы:"Магия утра" (Вода, Зарядка, Чтение), "Здоровье спины", "Учим английский".

- **"Пинги" и Реакции (Social Interactions)**

    - Зачем: Сейчас социалка пассивная (вижу статусдруга). Нужно активное взаимодействие.
    - Идея: Кнопка "Пнуть" (Nudge) друга, который еще не выполнил привычку сегодня. И реакции (🔥, 👏) на выполнение друга в ленте/уведомлении.


### 🎨 2. Визуализация и Геймификация

- **Heatmap (Тепловая карта активности)**

    - Зачем: Как на GitHub. Визуально показывает "плотность" продуктивности за год. Очень мотивирует не допускать "дыр".
    - Где: В профиле пользователя.

- **Фото-подтверждения (Photo Proof)**

    - Зачем: Доверие в групповых челленджах.
    - Идея: Опциональная возможность прикрепить фото к выполнению (например, фото из спортзала илистраницы книги).
  
  Этапы реализации:
    1. Настройка окружения и БД:
       - Подключить Firebase Storage.
       - Обновить сущность`HabitEntry`(добавить`photoUrl`).
       - Написать миграцию БД.

    2. Логика работы с изображениями:
       - Реализовать`ImageRepository`(выбор фото, сжатие, загрузка).

    3. UI - BottomSheet деталей дня:
       - Создать компонент`HabitEntryDetailSheet`(это будет точка входа для ретроспективного добавления).
       - Подключить егок календарю в экранах статистики.

    4. UI - Моментальное добавление:
       - Добавить SnackBar действие на главном экране.
       - Добавить кнопку камеры в диалог ввода значений.
