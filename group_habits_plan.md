# План реализации групповых привычек

## 🎯 Цель
Реализовать полноценную систему групповых привычек с приглашениями друзей, совместным прогрессом и уведомлениями.

## 📋 Этапы реализации

### Этап 1: Модели данных и архитектура (1 день)
**Контрольная точка 2.1: Модели для групповых привычек**

#### 1.1 Создать модель HabitInvitation
- Статусы: PENDING, ACCEPTED, DECLINED, EXPIRED
- Поля: id, habitId, fromUserId, toUserId, message, status, createdAt, respondedAt
- Extension функции для работы с приглашениями

#### 1.2 Обновить существующие модели
- Habit: добавить поле maxParticipants (лимит 10), inviteCode для быстрого присоединения
- User: добавить статистику групповых привычек
- HabitEntry: расширить для отображения прогресса участников

#### 1.3 Создать Entity, DAO, мапперы
- HabitInvitationEntity, HabitInvitationDao
- Обновить HabitEntity с новыми полями
- Миграция базы данных (версия 2 -> 3)

### Этап 2: Бизнес-логика (1 день)
**Контрольная точка 2.2: Repository и Use Cases**

#### 2.1 Расширить SocialRepository
- Методы для работы с приглашениями в привычки
- Получение участников групповых привычек
- Управление участниками (добавление/удаление)

#### 2.2 Создать Use Cases
- SendHabitInvitationUseCase: отправка приглашения в групповую привычку
- AcceptHabitInvitationUseCase: принятие приглашения
- DeclineHabitInvitationUseCase: отклонение приглашения
- GetGroupHabitProgressUseCase: получение совместного прогресса
- LeaveGroupHabitUseCase: выход из групповой привычки

#### 2.3 Обновить существующие Use Cases
- AddHabitUseCase: поддержка создания групповых привычек
- GetHabitsUseCase: фильтрация личных/групповых привычек
- MarkHabitCompleteUseCase: учет прогресса всех участников

### Этап 3: UI и интеграция (1 день)
**Контрольная точка 2.3: UI для групповых привычек**

#### 3.1 Обновить экраны создания привычек
- AddEditHabitScreen: переключатель личная/групповая привычка
- Выбор друзей для приглашения (из списка друзей)
- Настройки групповой привычки (лимит участников, правила)

#### 3.2 Создать экраны управления группами
- GroupHabitDetailsScreen: детали групповой привычки
- GroupProgressScreen: совместный прогресс участников
- HabitInvitationsScreen: управление приглашениями

#### 3.3 Обновить основные экраны
- HabitsScreen: отображение групповых привычек с индикаторами участников
- Карточки привычек: показ аватаров участников и общего прогресса

### Этап 4: Уведомления и финализация (0.5 дня)
**Контрольная точка 2.4: Уведомления и тестирование**

#### 4.1 Push-уведомления
- Приглашение в групповую привычку
- Участник выполнил привычку
- Напоминание о невыполненной привычке группой

#### 4.2 Строковые ресурсы и иконки
- Добавить все тексты для групповых привычек
- Иконки для групповых действий

#### 4.3 Интеграция и тестирование
- Навигация между экранами
- Проверка сборки проекта
- Тестирование основных сценариев

## 🔧 Технические детали

### Ограничения
- Максимум 10 участников в групповой привычке
- Только друзья могут быть приглашены
- Создатель привычки - администратор (может удалять участников)

### Синхронизация
- Firestore для реального времени обновлений
- Локальный кэш для офлайн-режима
- Conflict resolution для одновременных изменений

### UI/UX принципы
- Четкое разделение личных и групповых привычек
- Визуальные индикаторы прогресса группы
- Простой процесс приглашения друзей
- Мотивирующие элементы (прогресс-бары, достижения группы)

## 📊 Ожидаемый результат
- Полноценная система групповых привычек
- Интуитивный UI для совместного отслеживания
- Мотивация через социальное взаимодействие
- Готовность к следующему этапу (челленджи)

## ⏱️ Временные рамки
**Общее время: 3.5 дня**
- Этап 1: 1 день
- Этап 2: 1 день  
- Этап 3: 1 день
- Этап 4: 0.5 дня

## 🎯 Критерии успеха
- Проект собирается без ошибок после каждого этапа
- Пользователь может создать групповую привычку и пригласить друзей
- Участники видят совместный прогресс в реальном времени
- Работают уведомления о активности группы
- UI интуитивен и соответствует дизайн-системе приложения
