# Чек-лист ручного тестирования челленджей и геймификации
- [создание привычки]
    - Открой экран создания привычки presentation/ui/habits/.
    - Создай привычку (PERSONAL или GROUP). Убедись, что в списке появилась карточка и isActive = true.
- [создание челленджа]
    - На экране привычки создай челлендж: выбери даты (начать сегодня, окончание через 1–2 дня), задай тип (для быстрой проверки удобно COMPLETION_RATE).
    - Ожидаемо: после создания карточка челленджа видна в списке, участник — создатель.
- [приглашение друга и вступление]
    - Пригласи друга в челлендж (через UI приглашений/друзей).
    - Под тестовым аккаунтом друга — прими приглашение/вступи.
    - Ожидаемо: участник добавлен, лимиты соблюдены, статус ACTIVE.
- [выполнения привычек и прогресс челленджа]
    - Отмечай выполнение привычки на нужные даты.
    - Ожидаемо: прогресс в челлендже обновляется, поле updatedAt меняется.
- [выход из челленджа]
    - Выйди из челленджа под вторым пользователем.
    - Если остаётся один создатель — статус должен стать CANCELLED. Иначе — остаётся ACTIVE.
- [автозавершение челленджа]
    - Создай челлендж с endDate = сегодня и подождите до 00:00, либо создай с endDate = вчера (если UI позволяет), затем открой экран/обнови прогресс.
    - Ожидаемо: статус COMPLETED, определён победитель согласно правилу типа челленджа.
- [уведомления]
    - Если FCM настроен, проверь отправку:
        - Присоединение к челленджу → создатель получает уведомление.
        - Выход/отмена/завершение → участники получают уведомления.
    - Если FCM не активен — проверь, что ошибки отправки не ломают flow (мы их гасим).
- [достижения и очки]
    - Открой экран достижений (presentation/ui/achievements/).
    - Выполни несколько действий (создание привычки, выполнения, участие/победы в челленджах), обнови экран:
        - Проверь, что прогресс достижений растёт, баллы начисляются.
        - Категории корректны (enum→String маппинг уже синхронизирован).
- [соц. статус и статистика]
    - Открой раздел профиля/статистики. Убедись, что:
        - Кол-во друзей, групповых привычек, участие/победы в челленджах отображаются.
        - Прогресс уровня пользователя и заголовок уровня корректны.

## Edge cases
- [повторное вступление] Попробуй вступить в челлендж дважды — должно дать ошибку.
- [лимит участников] Если достигнут лимит (10) — отклонение с понятным сообщением.
- [не друзья с создателем] Попытка вступить без дружбы — отказ.
- [пустые периоды] Нет выполнений — прогресс 0, завершение по дате работает.
- [офлайн] Отключи сеть, отметь выполнение — локально ок, при восстановлении сети синхронизация не ломает состояние.
